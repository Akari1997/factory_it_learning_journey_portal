# Factory IT Learning Journey Portal

This repository contains the initial scaffold for the **Factory IT Learning Journey Portal**, built with **React**, **TypeScript**, and **Tailwind CSS**.

## Getting Started

### Install Dependencies

Using pnpm:

```bash
pnpm install
pnpm dev
```

Or using npm:

```bash
npm install
npm run dev
```

### Access the Application

Once the development server is running, open the following URL in your browser:

```text
http://localhost:5173
```

to view the prototype.
